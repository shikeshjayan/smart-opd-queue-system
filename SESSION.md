# SESSION.md — Smart Health OPD

Resumable session notes for the Smart Health OPD hospital token system.

## Stack
- Next.js 16.3.1, React 19.2.8, Tailwind CSS v4 (PostCSS), TypeScript 5.
- **No real backend** — all data is frontend mock data in `src/services/data.ts` with ~300ms `delay()`.
- Path alias: `@/*` → `src/*`.

## Phase 15 — Patient Medical Documents & Reports
- **Domain (`services/medical-documents`)**: self-contained service with `types.ts` (8 controlled `DocumentType`s in configurable `DOCUMENT_TYPES` ({type,label,category,uploaderRoles}) → `DocumentCategory` lab/imaging/prescription/other; model per spec: id, patientId, hospitalId?, encounterId?, type, title, fileId, mimeType, size, documentDate, hospital/dept names, uploadedBy(+id/role), source system|patient_provided|external, version, amendedFrom/amendmentOf, status active|archived|deleted, access.hospitalIds/grantedUserIds). Seeds cover all categories incl. a patient-provided Previous Cardiology Report and cross-hospital (hos_005/hos_006) docs for the authorization demo.
- **Secure file store (`file-store.ts`)**: native IndexedDB (no deps) holds file blobs keyed by `fileId`; metadata stays in localStorage. `requestSignedAccess(user, docId, view|download)` re-authorizes then returns a short-lived object URL (+15 min expiry) — never a permanent public URL (§7/§21). Seeds generate SVG "report" blobs (previewable + downloadable); missing/unavailable files → "Preview unavailable".
